# 需求

本文定义当前 cu-cli Viewer 的交付范围，以用户最新明确确认的需求为准。使用说明见 [README](../README.md)，进度见[开发计划](dev-plan.md)。

2026-10-27 已进入原型对齐的 React UI 落地规划。视觉及交互细节以 [UI 改造需求](ui-redesign/requirements.md)为准，实施阶段与验收统一维护在[开发计划的 UI 迁移章节](dev-plan.md#ui-redesign-react-migration)；计划更新不代表新 UI 已实现。未冲突的解析、格式支持、资源交付与只读职责继续有效。

## 目标与职责

提供 React/TypeScript 组件，让 cu-cli 在浏览器中并排展示原始 PDF/图片和 CU 分析结果，并在结果与真实来源间关联定位。

- 已确认下一版优先服务 CU 开发者、技术实施及技术测试人员，保持只读，不加入字段纠错、人工审核状态或修改保存。
- 本轮按已确认原型规划 UI 改造，包括 Fields 内的字段／值检索与同级展示排序；保持既有调用兼容，不迁入 toolkit、不发布版本，不新增跨文档批量浏览、全文检索或对比。
- Viewer 只负责渲染，不调用 Analyze、不依赖 CU SDK，不认证、不上传、不管理 analyzer、不轮询 LRO。
- CLI 负责取得源文件和原始结果，并调用独立 Viewer 包；Viewer 项目提供预构建页面、只读本地服务、浏览器启动及生命周期，不反向依赖 cu-cli。
- 原始需求已约定 `cu analyze sample.pdf --view`：分析完成后将源文件及原始结果交给浏览器 Viewer。不带 `--view` 时不自动打开 Viewer。
- 后续已确认 `cu analyze sample.pdf --view --result sample.result.json`：只读取已有源文件和 JSON，跳过分析、登录和服务调用。无效或缺失的结果必须报错，不得回退到重新分析。
- 已确认首版每次查看一份本地 PDF/图片；现有批量和 URL 分析保持原样，不新增这些输入与 `--view` 的组合。
- 保持组件与 CLI 职责分离，Viewer 可以独立开发、运行演示和测试。
- Viewer 独立发行和更新，cu-cli 通过兼容依赖自动安装它，不内嵌资源副本。普通用户不需要开发环境；缺失/损坏安装通过原安装渠道修复，不在 `--view` 时自动下载。

## 组件输入

| 输入 | 要求 |
| --- | --- |
| `source` | `File \| Blob \| ArrayBuffer \| string`，提供原始源文件或浏览器可访问的 URL。 |
| `result` | `unknown`，传入已解析的原始 CU JSON 对象；支持 Succeeded envelope 或 inner result，不要求调用方标准化或构造 SDK 模型。 |

不修改调用方输入，不把内部 CU/PDF.js 类型作为集成契约。下一版为已确认的 React 排序需求规划可选初始顺序、受控顺序与变化回调，不改变上述两个必需输入；具体契约按 UI 开发计划冻结，不预先开发其他通用定制 API。

## 源文件与导航

- 支持 `.pdf`、`.jpg`、`.jpeg`、`.jpe`、`.png`、`.bmp`、`.heif`、`.heic`，图片使用公共适配层。
- 提供缩放、平移、Fit page/width、旋转、上一页/下一页、跳页及当前/总页数；支持多页 PDF。
- BUG-010（新增截图问题）：选择 150% 等固定比例后，整页四边必须在实际滚动范围内，原生滚动条／滚轮能够访问四角，不能因锚点平移产生负坐标裁切。保留所选百分比、页码、Table 3 等关联字段范围、来源几何及手势锚点；旋转、先滚动再拖动和小比例切换后也成立，不以切回 Fit page 代替修复。
- BUG-008：常规缩放期间持续显示同一来源、同一页、同一旋转角度的已绘制预览，离屏新光栅完成后再替换，不能仅隐藏 Loading 文字却留下空白。首次加载、来源／页／旋转变化及真实错误仍明确显示实际状态，不沿用不匹配的旧画面；当前渲染和来源层的就绪、命中、焦点及锚点约束不变。
- Hover/选择结果关联真实来源；仅显式选择或定位才跨页，悬停不翻页、不滚动原文。缩放、旋转、平移及视口变化后仍对齐，无来源时不补造区域。
- 多来源字段选中范围包含本页全部真实片段，适用于普通值、嵌套值和数组单元格；右侧仍只选同一字段，不推断相邻字段。相邻同列多行可显示一个精确、无填充的装饰外框，但不合并真实多边形、扩大命中或把空白当来源；跨栏、分散或会圈入其他字段（含已隐藏的缺失字段）时保留原轮廓，整组和原生表格不强行合框。来源数量及当前定位序号与框数分离，浮层仍位于当前连续来源块下方，分散位置各自定位，不强行拉动视口；失效或不在本页的定位点不得借其他片段伪造成功浮层。
- 显式定位保持 zoom/rotation，仅在目标位于可见视口外时调整平移，已可见目标不移动。
- 选中／临时显示框只在装饰层使用精细抗锯齿，避免小数坐标和设备缩放造成各边粗细不一；原线宽、颜色、真实坐标、语义填充和点击命中不变。同一已选范围不重复叠描，预览内容与实际固定状态保持独立。
- Source/Result 保持双栏、最小宽度及独立滚动，支持 Chrome/Edge 中的键盘、可见焦点和 ARIA 信息。
- 无效文件、JSON、页码和来源明确提示；源文件失败不隐藏有效结果，替换/取消/卸载释放自有资源。

## 结果视图

从原始 JSON 识别 GA `2025-11-01` 与 Preview `2026-06-01-preview` 的适用非空数据，按以下顺序生成标签，无值隐藏，未知属性保留在完整 Result：

`Fields → Markdown → Paragraphs → Figures → Signatures → Metadata → Result`

Tab 栏按可用宽度自动收纳，超出部分通过右侧 `...` 下拉菜单选择，不使用横向滚动。选中的视图标签始终可见，保留方向键及 Home/End 切换；菜单支持上下键、Home/End、Enter/Space 和 Esc。移除 Code 标签。

| 视图 | 要求 |
| --- | --- |
| Fields | 显示名称、原值、已有置信度及来源；支持嵌套对象/数组、多来源区域、折叠和固定选择，区分缺失与 `0`、`false`、空字符串、`null`。折叠对象显示真实值摘要，长值单行省略但可查看／复制完整原值，名称旁不显示 `n selected`；数组数量只在 Value 保留 `N items`，不在名称旁重复 `[数量]`。不影响选中、业务行号及来源。源表格点击临时聚拢已有的可靠关联字段，不新增 Document Tables 分组、不自动重排；表格无提取字段时解释无对应项。 |
| Markdown | 安全展示标题、列表、表格、代码等常规格式；危险 HTML/URL 不能执行。 |
| Paragraphs | 保留 CU 顺序、role/页信息，关联全部真实来源。 |
| Figures/Signatures | 从已加载 source 的真实区域裁剪，显示已有 metadata 并定位，不推断签名状态或虚构图片。 |
| Metadata | 只读字符串键值、保留顺序，支持单值复制。 |
| Result | 成熟交互 JSON 树支持合理规模的大结果，展示完整原始输入/envelope，包括 usage；根展开、嵌套折叠。 |

切换标签不重挂 Source，不重置页码、缩放、旋转、平移或固定项/区域索引；切换 content 时重算适用视图。

## 已确认的来源交互

- Legend 从齿轮设置独立到 Source 顶部文件信息与设置之间；面板宽度达到 1040px 时常驻五项简版图例，较窄时收为 Legend 按钮，完整五项说明按点击展开。断点按 Source 容器而非整个窗口判断，顶部工具栏保持原 57px 高度，Legend 本身不增加行高。齿轮保留阈值及三个总开关；宽版和完整 Legend 共用可点击、可键盘操作的五项 Source 分类显示状态，默认全开，关闭项空心斜线／弱化文字，但保留名称说明。Legend／设置互斥，支持合理的 Esc／关闭焦点恢复及外部／键盘移出关闭。
- BUG-003 已确认底部文档控制栏：来源视口下方以 44px 行高呈现居中页码和靠右的缩放／适应／旋转，保留原操作、输入校验和焦点恢复。BUG-005 确认旋转在所有支持宽度下直接显示，移除顶部 More 和独立布局重置菜单入口；拖动分栏和双击分隔条复位保留。BUG-009 已确认将必要状态／来源导航并入该行左侧，移除额外的 34px 提示行和常驻手势说明；状态内容变化不增减行高，避免由状态栏引起视口或 fit 变化。完整来源状态通过提示／无障碍描述保留，非视觉手势帮助不变。报告／图片未要求常驻 X；后续用户明确选择移除底部 X、不新增替代按钮，保留已有 Esc／原文空白处点击及原清除逻辑。fit 使用实际可用空间，不修改原始文件或来源坐标。
- 分类开关只控制 Source 填色与装饰外沿，不筛选右侧 Fields、修改低置信度判定／提示、计数、原始数据或来源几何，也不移除来源命中、固定／预览轮廓。字段／表格总开关优先，对应禁用项显示原因；低置信强调关闭时两项 Low 禁用，原有正常色渲染归 Field／Table 类控制。N/A 继续表示“未返回置信度”，不同于真实 `0` 和“值未返回”，在任一字段／表格总开关开启时可控制。子项选择随现有偏好保存且总控关闭不重置；旧 v1 记录缺少分类字段默认全开，外层格式／键及必需公开输入不变，非法分类映射明确报错，不静默覆盖。
- 当前 Tab 决定适用来源框，不同 Tab 的框不混画；Fields／表格值按提取类型与自身置信度使用新 UI 语义色，不再继承根字段身份色。其余真实来源及表格整框保留；表格导航采用下面已确认的直接定位方式。
- 右侧字段 hover 显示原文附近的名称/Value/已有 Confidence，段落只显示 Content。其他来源框保留，预览不替换固定选择。
- 普通字段／数组值的临时预览与固定选择使用相同的完整实线外框和安全合框规则，不再只以虚线框住当前片段；视觉一致不表示状态合并。鼠标指向或明确焦点不产生固定选择、不替换原固定项、不改定位序号、页码、视口或表格限定范围，离开后只清除临时框；段落、分组及其他详情预览保持既有样式。
- 字段／数组值浮层正文使用固定深色，不随置信度变色；只有 Confidence 标签、分数及 Gauge 沿用原有状态色。阈值、高亮开关、未知分数和真实 0 的语义不变，不影响源区填充、Fields 低置信度提示或段落 Content。
- Fields 的普通当前字段整行与数组当前单元格统一用浅紫选中背景，普通整组及其内嵌数组正文／固定序号用连续选中背景，不再叠加选中框线或侧线。低置信度标签及键盘焦点独立保留；明确源区选择的短暂强调统一为背景渐淡，减少动态效果时静态可辨，不改字段尺寸、来源坐标或排序偏好。
- Fields 导航工具区仅保留匹配计数和上一／下一字段，移除“查看当前选中值”信息图标及其专用单值判断。完整值详情仍通过字段主入口／数组单元格上的 F2、值操作菜单及折叠摘要访问，相关复制与焦点规则保留；不因移除全局快捷入口而删除共享详情能力或菜单图标。
- 右侧内嵌数组表格改用单层 1 CSS px 网格：横线 `#E7EBF0`、竖线 `#EEF1F5`，外沿／表头底线／固定序号右边界 `#DCE3EB`。保留分离边框布局和原边框占位，仅单侧着色以消除内部双线，固定序号不再叠加阴影。原列宽、各表既有行高、固定序号不透明背景、原生横向滚动及源区定位不变；这不是对原始 PDF 表格线或浮层定位的修改。
- 交互色采用同一靛紫系分层：源区 hover `#8C70C2`、固定 `#5B21B6`；Fields hover `#EEE7FF`、实际选中 `#E5DAFF`，表格关联范围及数组行列上下文为更淡的 `#F8F5FF`。hover 轮廓柔化、浅底稍加强，使左右视觉强度更接近，同时保留轮廓与正文的可读性。左右普通行、折叠父级与数组单元格 hover 联动且不改变视口／选择；选中优先、同一字段再次指向不变浅。来源定位背景从 `#D8C6F2` 渐淡至实际静态底色，时长及减少动态效果行为不变。交互底色上的次要文字保持 `#526276`，原有置信度色板、正文、命中及完整框形状不变，框的额外留白方案不实施。
- 2026-10-28 最新确认：独立 Tables 标签一并移除，且不新增 Document Tables 分组。点击真实表格空白／边框或按 Enter／Space，切到 Fields 并定位已有的可靠关联字段／数组；提取值点击仍优先定位自身。关联依据同页真实多边形的完整包含，重叠表格歧义不猜测，多字段同时标记，不默认选第一个。无对应时明确提示，不造字段；原生表格内容、合并跨度、缺口及解析问题保留在完整 Result。
- 后续已确认：可靠表格关联默认进入临时 `Related fields only`，只展示关联目标的原有结构及必要祖先。组标题／子字段用连续浅紫背景，具体选中值稍深，不叠加关联框线／侧线；置信度标签语义色不变。相关值的选择、详情、复制及标签切换保留范围，不清空已有搜索／筛选。
- `Show all` 恢复进入范围前的展开、纵向及数组横向位置，保留当前选择和关联提示，不撤销范围内明确修改的搜索／筛选。范围内禁用拖拽、Alt 排序和 Reset order，临时投影不改写原始 JSON、已保存顺序或宿主受控顺序。
- 仅悬停范围外的源值不退出；明确选择外部源字段退出并优先定位新字段，不能被旧滚动恢复覆盖。清除选择恢复原列表，换文档丢弃旧范围／快照；无可靠关联时只提示，不限定到空范围。恢复折叠父级后关闭详情有安全的可见祖先焦点回退。
- 定位不清除筛选，不重置源页、缩放、旋转、平移或源区焦点；拖动不导航。没有提取字段、只有原生表格的内容也保留 Fields 空状态及 Result 入口，不把版面表格自动复制为字段。
- 保留 `pages[].words[].source` 的真实 OCR 数据解析与错误提示，但新 UI 不再绘制常驻黄色 OCR 底层；未提取文本不因有 OCR 数据而被染色，不改变原图或 JSON。
- 浮层提供键盘等价信息、Esc 关闭、有界位置和长值滚动。
