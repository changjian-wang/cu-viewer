## 1. 目标、范围与交付顺序

将现有“按字段身份分配颜色”的结果展示，调整为信息密度更高、干扰更少、便于根据置信度连续查阅的只读工作台。

交付顺序：

1. 先生成本文，区分明确需求、已确认的设计取舍和原型探索。
2. 使用独立 HTML、CSS、JavaScript 制作可交互原型，不修改现有 React 组件、样式、接口、入口或构建配置。
3. 原型完成确认并冻结在本地提交 `01c515e`（包含 `d31b613` 之后的菜单误预览修复）；React 实施与验收统一维护在[现有开发计划](../dev-plan.md#ui-redesign-react-migration)，不修改冻结的原型来迁就实现。

本轮不调用 Analyze，不登录、不上传，不增加编辑、纠错、批注、审核状态、审批或修改保存流程。需求中的 review 指只读查阅，不代表引入人工审核系统。

## 3. 页面结构与视觉原则

- 保留左侧源文档、右侧结果的双栏结构和独立滚动。
- 双栏分隔条支持拖动和左右键调整，保留源区 570px、结果区 440px 的最小宽度；字段名／值的列宽也支持拖动及键盘调整，双击恢复对应默认比例。
- 原型将宽度比例与已有排序偏好一并保存在当前浏览器；旧版偏好仍能读取，补齐新增布局默认值，不丢失原来的字段顺序。
- 源文档工具栏聚合文件信息、页码、缩放、适应页面／宽度及高亮设置入口。
- 当源区变窄时，旋转通过“更多”菜单继续可用；菜单同时提供 Fit page、Fit width 和布局宽度重置。
- Fields 以紧凑表格提升信息密度，不再用大量彩色圆点标识字段身份。
- 字段名和值使用 12.5px，内嵌表格值使用 11.5px，Confidence 保持 11px 的次要中性色；结果标签与顶部工具区总高度控制在 150px 以内。
- 缺失值、不可用置信度、摘要和表格行号等次要文字通过字号与字重保持层级，不使用过浅的文字色；这些文字与实际背景的对比度至少为 4.5:1。
- 对象使用真实字段层级、缩进和展开／折叠控件；不为还原参考图而虚构分组或修改原始结果。
- 对象数组可展开为内嵌表格，方便横向比较 LineItems 等行项目；保留原始业务行顺序。
- 数组表格与 Fields 内容左缘对齐，不再额外缩进；对象／数组名称的层级缩进仍用于真实字段树。`#` 与行序号在横向滚动各阶段贴住真实裁剪边界，背景不透明、宽度对齐，滚走的文字不能露出边界；拖动滚动条不能改业务行顺序。
- UI-53 内嵌数组采用单层 1 CSS px 网格，横线 `#E7EBF0`、更淡的竖线 `#EEF1F5`，外沿／表头底线／固定序号右边界 `#DCE3EB`。保留 `border-collapse: separate`、零间距及原边框盒，仅右／下侧绘制可见内网格并补齐顶部／左外沿；固定序号只保留右边框，不叠加分隔阴影。不得通过减少边框占位改变原列宽或行高；紫色交互背景、粉色低置信度值标签及独立焦点保留，不把选中状态再画成边框。
- 初始预算计入所有根字段行；首个非空数组按业务行及表头计数，无法投影为表格时按实际新增子行计数。剩余预算按展示顺序分配给首层对象，不递归展开子组；放不下的组保持折叠。根行已达到 40 时不额外展开，不因首个数组过大而自动改开后续数组。
- 默认展开只在文档／内容上下文初始化时应用，不因阈值、搜索、排序或标签切换重新执行；手动展开与显式来源定位不受 40 行限制。
- 普通对象折叠时的 Value 按 UI-47 显示真实提取值摘要，不生成 `N properties` 或把虚构计数用于搜索；完整结构、复制及原始 Result 不丢失。数组数量按 UI-49 仅在 Value 列显示一次 `N items`，名称旁不再重复 `[数量]`；列宽仍按内容紧凑分配，不统一设置 130px 下限。
- 纸张阴影、源区／字段滚动条主题及主表头 4px 圆角沿用冻结原型的样式，均限定在共享组件内。
- 置信度是次要信息，常驻数字使用较淡但满足可读性的文字颜色，低置信度分数也不额外抢占视觉注意力。
- 普通字段、数组及整表关联统一使用浅紫导航底色，不以外框或侧线表达选中；键盘焦点单独可见，不移除正常焦点提示。不引入字段身份色、不把选中伪装成低置信度或审核状态。
- 实际选中／整组选中的标题、子字段、数组正文及不透明固定序号按 UI-51 使用 `#E5DAFF`，表格关联范围为 `#F8F5FF`，hover 按后续 UI-52 为 `#EEE7FF`；不叠加框线、组侧线或后代侧线。数组单值的行号／列标题上下文同为更淡的 `#F8F5FF`，不因单值选中涂满无关行列，低置信度标签和行列尺寸不变。
- 数组键盘操作只在实际焦点单元格上显示一层 1px 细线，值按钮与更多按钮不再各画一层焦点框；菜单自身的焦点可见性保留。鼠标点击不常驻键盘框，标记不改变行高、列宽及置信度值标签底色。
- 已选字段的来源保持实线轮廓；普通字段／数组值的临时预览按 UI-46 使用相同的完整实线框，其他视图预览保留既有样式。两个状态与绘制层仍独立，离开目标进入空白、其他分组或其他控件后清除预览，不能把临时预览误留为固定选择。
- 鼠标预览由实际指针移动触发，键盘预览由明确聚焦触发；菜单消失、详情展开或列表重排造成的自动进入事件不能触发背后其他字段的预览。值操作菜单打开期间不预览背景字段。
- 普通分组定位也采用连续背景，点击其子值后回到单值底色；整表关联范围内点子值则按 UI-41 保留关联块及限定范围。左侧真实来源描边不变。
- 分组的定位按钮在该行悬停／聚焦时显示，并始终预留空间；按 UI-47 移除所有 Fields 名称旁的 `n selected`，但保留选中背景、全部后代选择及源区真实数量说明。组级 Confidence 留空；数组默认列标题左对齐、字重 600，行号字重 400，未关联行号为白底，目标行列提示按 UI-40 的淡背景处理。
- 切换结果标签时分别保留结果滚动位置及内嵌表格横向位置；原有字段展开、筛选、源页、缩放和旋转不被重置。
- 参考图中未展示的现有结果视图不因此删除，旧图中的 Code 也不因此恢复。本轮不重新定义现有结果标签的交付范围。

## 4. 高亮语义

### 4.1 源文档色板

比较对象是字段或单元格自身已有的置信度，使用未四舍五入的原值比较阈值。

| 提取类型 | 条件 | 背景色 | 文字色 |
| --- | --- | --- | --- |
| 单字段 | confidence ≥ threshold | `#E8F5E9` | `#1E3A2A` |
| 单字段 | confidence < threshold | `#FCE8E6` | `#9B1C1C` |
| 表格单元格 | confidence ≥ threshold | `#E8F1FF` | `#1E40AF` |
| 表格单元格 | confidence < threshold | `#FFE8EC` | `#9B1C1C` |
| 任意提取值 | confidence 不可用 | `#F1F3F5` | `#374151` |
| 未提取文本 | 不适用 | 无高亮 | 原文颜色 |

- confidence 为 `0` 是有效值，不等于缺失。
- 缺失置信度不能默认视为高置信度，也不能借用父级或表级置信度替代。
- 低置信度表示“优先检查”，不表示一定错误；高置信度不表示已人工确认。
- 新设计不保留字段查阅模式下全量 OCR 词的常驻黄色底层。未提取标题等不应仅因为存在 OCR 数据就被染色。
- 源区类型显示开关优先于低置信度强调：关闭源字段高亮后，低置信度开关不能重新显示其源区填充；表格同理。
- 关闭高亮不隐藏字段值，也不使定位操作失效；选中目标仍可用轮廓指示。

### 4.2 右侧 Fields 的颜色

- 正常值不因置信度使用绿色或蓝色标签填充；未选中时保持白底或中性背景，选中时的浅紫底仅代表导航。
- 只有低置信度的值使用浅红／浅粉底色，不染整行。
- 字段块及数组单元格的选中／关联浅背景只表达导航，不覆盖值标签自身的置信度颜色；即使选中，低置信度标签仍保持原粉色，邻接数据单元格不因单值的行列关联而整体染色。
- Show field highlights／Show table highlights 只控制源区填充，不能清除右侧字段或数组已有的低置信度提示；右侧提示仅受 Highlight low confidences 控制。
- 无置信度值不伪装为低置信度。
- Confidence 列保持弱化的中性色，颜色强调集中在 Value。

### 4.3 原文文字色的实现边界

独立原型使用明确标注的模拟文档，可以直接呈现色板中的目标文字色。正式组件当前使用 Canvas 渲染 PDF／图片，不能通过普通 CSS 独立重着色底图中的文字。

2026-10-27 已确认：保留真实原文文字，不增加 OCR 文本重绘或遮盖原文的方案；使用透明／混合高亮与轮廓表达状态。状态文字色不用于重绘底图，右侧低置信度值继续按既有规则显示；Flyover 正文按 UI-45 采用固定深色，仅置信度标签保留状态色。底图高亮的叠加方式在真实样本视觉验收中冻结，不能用不透明色块遮住原文字。原型的模拟文字不代表真实渲染已完成。

2026-10-28 色彩清晰度补充：源区以完整色强（`fill-opacity: 1`）配合 `multiply` 混合，去掉原有额外的 75% 淡化。白底来源区域的实际合成像素应与五种语义背景色相同，不能仅检查 SVG 的颜色属性。保留真实来源坐标、阈值、原始 Canvas 和原文黑色字形，不扩大来源框、不新增字段身份色；以 PDF／图片的实际合成截图验证深色文字没有被覆盖。

2026-10-28 外观复核后确认：可在真实多边形外围增加 1 CSS px 同色圆角绘制外沿，但使用独立、不可交互且不进入可访问树的装饰层。实际多边形仍单独负责命中、键盘选择及浮层锚点，不能用装饰路径替代来源数据；源区开关同时控制装饰外沿。

### 4.4 Hover 与固定选中的交互色

| 状态 | 源区轮廓 | Fields 导航底色 |
| --- | --- | --- |
| Hover／临时预览 | `#8C70C2` | `#EEE7FF` |
| 实际固定选中 | `#5B21B6` | `#E5DAFF` |
| 表格关联范围 | 不新增身份色 | `#F8F5FF` |

- 使用共享交互色，普通行、折叠祖先和数组单元格的源区／右侧 hover 必须联动；不得靠自动展开、滚动或选择来制造提示。
- UI-52 将 hover 的左右强度收敛：源区使用更柔和的中紫轮廓，Fields 使用稍明显的浅紫底色；保持同色系而非强行同色值，避免浅色细框看不清或深色整行影响正文。固定选中、关联范围、定位强调及键盘焦点配色保持不变。
- 选中优先于 hover。再次指向已选字段／选中分组的后代时不变浅，复用已有固定框、不重复绘制临时边框，但保留当前浮层及片段定位状态；源区固定层在其他预览层之后绘制。折叠后代表当前隐藏子值的祖先也保留明确选中底色，表格关联仍只是上下文。
- 固定与临时显示轮廓采用 `geometricPrecision`，不能沿用语义填充层的 `crispEdges` 将 1.8px 小数描边硬吸附到整像素；不改 Source 坐标、不做命中取整、不增粗或重新栅格化原文，配色按本节表格。DPR 1／1.25／2、不同缩放和四分之一旋转后，各边透明度覆盖的等效厚度应保持原定线宽（像素采样容差 0.03 CSS px）；同一已选范围内不允许重复抗锯齿叠描。
- 保留完整实线／合框几何、原始命中、线宽、无填充与状态独立；其他视图既有线型不变。源区不叠加交互色实填，原有置信度底色、低值标签、浮层正文与 Confidence 色板都不改。用户已跳过额外框距方案，本次不增加 padding 或扩大显示框。
- 交互底色上的中性 Confidence／数量／缺失说明等次要文字使用 `#526276`，不改实际值的正文色或覆盖内联低置信度红色。静态 hover／选中底色上的次要文字对比分别约 5.20:1／4.69:1，满足至少 4.5:1；源区 hover／选中轮廓对现有底色的最低对比分别约 3.42:1／7.62:1。

## 5. Highlighting 设置与图例

- 点击源工具栏右上角齿轮打开轻量浮层，不增加常驻第三栏。
- 设置面板包含置信度阈值和三个开关，完整图例按后续 UI-54 移到工具栏独立入口：
  - Show field highlights
  - Show table highlights
  - Highlight low confidences
- 阈值接受 `0–1`，包括端点；非法、空白、非有限或越界输入必须明确提示，不悄悄改成默认值。
- 已确认原型及本次 React 迁移的默认阈值为 `0.70`。
- 设置面板名义宽度为 326px，采用 35×21px 滑动开关及 116px 数字输入框，不再重复嵌入图例；输入支持 `0.01` 步进，默认显示 `0.70`，不能为补齐两位小数而丢失 `0.699` 等实际精度。面板高度受源区约束，空间不足时内部滚动。
- 修改合法阈值后立即更新状态与高亮，不修改结果数据。
- 图例同时解释正常字段、正常单元格、两种低置信度及无置信度状态，完整名称／说明／色板复用同一组定义，不改真实 `0`、未知分数或阈值的语义。
- UI-56 将五项图例改为真正的分类切换按钮，宽版短标签与完整图例共享状态，鼠标可点击整项的色块／文字，Enter／Space 等价。按钮使用 `aria-pressed`，单击只改变该类 Source 填色及同色外沿；不改变右侧字段、计数、筛选、置信度提示、数据、来源 points／命中、固定／预览轮廓或视口。开关目标至少 24px，关闭时空心斜线色块与较淡文字仍清楚可读，不仅依赖颜色表达。
- 保留 N/A：它表示有来源但未返回置信度的状态，不是低分 `0`，也不是字段未返回。分类显示默认全开；Source 字段／表格总开关优先，禁用的分类说明原因且保留自身选择，不能点击子项而自动连带打开总开关。N/A 在任一字段／表格总开关启用时可操作，两者都关闭才禁用。
- 既有 Highlight low confidences 仍决定低置信度强调。关闭时两项 Low 分类禁用；源区原有低分值按正常色显示并归入 Field／Table 控制，说明同步为“All scored values while low-confidence emphasis is off”，不把它们误说成高分值。再次开启强调时恢复原有分类选择，不改真实阈值、分数或右侧筛选语义。
- UI-54 将 Legend 放到缩放／旋转之后、更多／设置之前的空白区。按 Source 容器的实际宽度响应：达到 1040px 时常驻 Field／Table／Low field／Low table／N/A 五项短标签与 10px 小色块；不足时仅保留 Legend 按钮，不部分裁掉项目、不换行撑高工具栏。原有 57px 高度、页码／缩放控件和文档视口保持，文件名仍按原规则省略。
- 点击 Legend 展示完整名称与说明的独立非模态面板，宽 310px、最大高 340px，保留完整 33×28px 色块，定位在入口下方并限制于源面板内。只在显式点击或键盘激活时展开，不因 hover 自动覆盖文档；无源文档时仍可查看说明。
- Legend／More／设置同一时刻仅打开一个。支持关闭按钮、Esc 和外部点击关闭；Esc／关闭按钮恢复对应入口焦点，外部输入及键盘移出不抢焦点，不能顺带清除字段选择。仅展开说明不写偏好；点击分类按现有规则保存 `sourceCategories` 五个布尔值，不写提取值，不修改源图、阈值、三个总开关或提取数据。旧 v1 记录未含该字段时默认全开，不改原键／外层版本或在读取时重写记录；提供的映射必须是完整、无额外键的五布尔值对象，损坏时明确提示并等待显式重置。冻结原型仍保留原有布局。

## 6. 源文档操作与来源定位

### 6.1 缩放与平移

- PDF 和图片视图都支持触控板捏合，以及 Ctrl／Command + 鼠标滚轮缩放。
- 普通滚轮和触控板双指滚动保留滚动语义，不劫持为缩放。
- 以指针／手势位置为缩放锚点，避免目标跳走；高亮与来源指向同步更新。
- 保留按钮缩放、适应页面、适应宽度及页码导航，不能只提供手势。
- 原型缩放范围为 25%–300%，属于演示边界，不自动替代正式组件的渲染容量限制。
- 拖动源文档可平移；缩放、旋转或调整布局后，来源区域仍对齐。

### 6.2 字段定位与跨页

- 标量字段与表格单元格在悬停／聚焦时显示同一种“更多值操作”入口，菜单包含真实来源页定位、完整值与置信度、复制；未提供来源时禁用定位，未返回值禁用复制。
- 对象／数组分组继续使用页码定位按钮；标量的目标页在值操作菜单中明确显示，例如 “Locate on page 2”。
- 点击标量字段的名称、值、置信度或行内空白，以及数组表格单元格，即选择并定位；来源位于其他页时自动切换到目标页，不要求先点击专用定位按钮。
- 显式选择与重绘后的焦点恢复分开处理；恢复键盘焦点不能重新生成悬停预览，也不能阻止显式定位为完整浮层留出空间。字段名、值、Enter、定位菜单及源区点击遵循同一选择语义。
- 再次悬停或聚焦已选字段的列表项／当前来源时，保留其固定选择，不重新降级为临时预览；鼠标经过该字段的其他真实来源区域时仍可临时预览。
- 悬停及键盘预览不自动跳页或滚动原文，不通过改变底部留白移动鼠标下的目标；对象／数组分组名称仍用于展开和折叠，不因展开分组而跳页。
- 对象／数组分组的页码按钮表示“定位整组”：选择全部后代叶字段，左侧同时描边当前页上的所有真实来源，不再以第一个子字段代替整个分组。
- 右侧标记已选分组及其后代，缺失或无来源的字段仍属于选择，但不生成虚构来源；分组选择不改值的置信度底色，也不引入批量审核或复选框。
- 分组定位不强制展开该组；折叠及再次展开保留整组选择。点击任一子字段或单元格后，切回单字段选择。
- 分组跨页时，页码按钮额外说明涉及的页数；底部显示分组名、字段数、当前页来源区域数与来源页选择器。优先定位当前页，否则定位该组的第一个来源页；切页后继续强调该页全部组内来源。
- 分组选择覆盖被搜索或低置信度筛选隐藏的后代，不擅自清除筛选，并明确提示；不同页面只强调其真实存在的区域。
- 分组定位不显示某个子字段的 Flyover，不生成汇总置信度；悬停子字段时仍可预览其值，离开后恢复分组强调。
- 源区底部提供清除选择入口，适用于单字段和整组；点击原文空白也清除选择，但拖动平移不清除。清除不改变页码、缩放、旋转、筛选、展开或排序。
- Esc 按层处理：先取消正在进行的拖拽／调宽，再关闭菜单或设置、完整值详情；没有这些上层界面时清除选择和预览，不需要刷新页面才能退出整组状态。
- 字段有多个来源时，优先使用当前页上的来源；当前页无来源时，定位第一个已有来源，并保留区域切换入口。
- 普通字段、嵌套字段及数组单元格选中后，当前页中该字段的全部真实来源片段保持选择；点击其中任一片段都仍是同一个完整字段选择。不得按名称、相邻行或相同文字猜测归属，不带入独立收件人／其他字段，不合并或扩大真实多边形。
- 显示外框与真实来源分离：同字段相邻多行可绘制一个无填充、无额外 padding 的装饰外框，覆盖连续块的精确边界。行间距不超过较小行厚度，短行方向一致、相邻行跨轴至少重叠较短行的一半，且框内不得触及其他字段来源；检查不受缺失字段是否隐藏影响。跨栏、同排分散片段、远距位置或碰撞时保留原轮廓，多个独立连续块各画一框。整组、原生表格及非 Fields 视图不因该补充合并来源。
- 合框不改变真实置信度填充、命中、来源数量、定位序号、浮层或最小显示范围。显示框不接收指针事件，框内新增空白仍按原有空白点击规则处理，不能成为新来源；普通字段值的临时框按 UI-46 与固定框复用安全合框逻辑，其他预览样式不变。
- 来源选择范围与当前定位片段分开：底部显示当前页来源数量及 `Location n of total`，上一／下一按钮只改变定位点，不能缩小选中范围。跨页时仅画本页真实片段，显式来源切换才跳页；定位点不在本页时不借另一片段显示浮层，来源页缺失仍明确报错，保留本页合法来源。
- 当前页定位保持缩放和旋转，只在必要时调整视口。
- 原型约定：点击源区域会使对应的右侧字段进入可见区域；若字段被筛选隐藏，则保留筛选条件并明确提示，不擅自清空筛选。
- 源表格不增加独立小图标、Rows/Columns 预览或弹窗，也不新增 Document Tables 分组。任一结果视图点击当前页真实表格空白／边框，切到 Fields，展开并强调已有的可靠关联对象／数组／字段；不复制原生表格、不默认选中第一个值。没有真实表格来源时不补造整框。
- 已有字段／单元格值的命中优先于表格区域，继续使用原有定位及详情操作。表格区域可用 Enter／Space 激活、上下键浏览；保持源区焦点、源页、缩放、旋转与平移，拖动不导航。整表悬停不打开浮层。
- 关联仅采用同页真实来源多边形的完整包含关系；不依赖字段名、表号或相同文本，来源同时属于多个重叠表格时不猜测。完整组可靠对应时定位组，否则只标记可靠叶字段，数组行对象不得代替可见单元格。父级来源只在后代没有自己的来源时才作为真实回退。
- 无对应字段或关联歧义时在 Fields 页脚明确说明，保留 Result 中完整原生数据；不清除搜索或筛选，隐藏的对应字段数量有提示。只有原生表格的内容也提供 Fields 空状态。普通标签往返不重放请求，仍保留 Fields 纵向与数组横向位置；提取数组单元格详情／复制保留，原生独立网格与当前表格导航已移除。
- 有可靠关联时自动进入临时 `Related fields only`，以同一 Fields 树投影只显示关联目标的原有完整对象／数组结构及必要祖先；部分数组仍保留真实业务行号／列结构。不新增字段或表格容器，不修改原始 JSON、排序偏好或受控顺序回调。
- 范围提示和 `Show all` 复用现有顶部摘要行，不新增常驻工具栏。原搜索、低置信度与缺失筛选照常相交；用户在范围内明确编辑的筛选不会在退出时被撤销。字段导航与数量继续使用同一匹配叶集合，分母保留全局叶字段数量。
- 点击范围内的值、打开／关闭详情、复制及切标签不退出范围；范围内禁用拖拽、Alt 排序和 Reset order。`Show all` 恢复范围进入前的展开、纵向及数组横向位置，但保留当前选择与关联底色。多次切换源表格仍只保留最初的全局视图快照。
- 明确选择范围外的源字段时退出范围并优先定位新字段，不能用旧滚动位置覆盖新定位；仅悬停不退出。清除选择恢复全局快照，换文档丢弃旧快照。退出后若原父级恢复折叠，关闭详情应聚焦并安全显示最近可见父级，而不是掉到页面 body。
- React 定位以完整字段行／数组单元格为目标，排除 Fields 固定表头及数组固定行号的实际遮挡范围，空间允许时保留约 8 CSS px 间距；目标已完整可见时不滚动，必须移动时将来源选择目标放在有效视区较靠上的位置。键盘浏览也不能让名称被固定表头盖住。
- 左侧明确选择（鼠标或键盘）后，普通字段、分组、数组单元格及表格关联块统一使用约 1 秒的背景渐淡（按 UI-51 为 `#D8C6F2` 到静态背景），不瞬时叠加描边，随后保留稳定浅底。重选可重放，悬停、右侧选择、菜单关闭及标签恢复不触发，不抢焦点、不自动打开详情。
- 尊重减少动态效果偏好，仅保留静态标记；切换目标、清除选择、切换文档或卸载时取消旧强调。该补充不修改冻结原型，也不新增页脚定位路径。
- 多来源字段保留当前页区域数量、全局定位序号和上一／下一来源区域操作，不能把来源定位误当成字段选择范围或字段导航。
- 没有来源的值仍可查看，但不能补造区域；定位能力不可用时明确说明。
- 原型增加上一／下一字段与低置信度筛选，作为查阅效率探索项，最终是否保留由原型评审决定。

## 7. Flyover

- 放在原文值下方，以原文值左边缘为默认锚点，不以右侧表格或整个查看器左边缘为锚点。
- 连续多行来源使用当前定位点所属的相邻来源块作为浮层布局边界，放在整段下方，避免覆盖同字段的后续行。只将间距不超过双方较小短边的片段连为布局块，缩放及四分之一旋转后规则一致；这只影响浮层和最小显示范围，不改变真实来源／命中多边形。相隔较远的位置各自定位，不把所有当前页来源强行纳入同一个浮层锚点或视口。
- 普通字段／数组值的悬停或明确焦点预览覆盖当前页完整字段，复用固定选择的安全合框逻辑与 1.8px 实线，无虚线、无填充，颜色按 UI-48 区分 hover／选中；当前片段只决定浮层所在连续块。固定项、定位序号、右侧选择与表格限定范围不受预览影响；不自动翻页、平移、滚动或预留空间。跨栏、碰撞和分散块与固定态一样安全回退；段落、分组及非 Fields 详情保留原线型和正文规则。
- 顶部小尖角说明来源关系；右边界不足时允许必要的水平避让。
- 已确认的边界规则：悬停时下方空间足够则显示完整浮层；空间不足时只保留来源轮廓，不显示被裁切的卡片，也不临时翻到上方。点击或显式定位后才允许最小滚动，完整显示下方浮层。
- 页底空间按显式选择的浮层所需高度动态预留；临时悬停、隐藏或恢复预览时保持已有留白，避免原文跳动。清除选择、切换文档或显式重新定位时重算，不保留固定的 200px 空白尾部。
- 使用紧凑两行气泡，宽度随内容收缩，最小宽度 148px、最大宽度 248px；短值目标高度不超过 60px，不再使用固定宽度的大卡片。
- 字段名使用中性小字，取消整条状态色标题栏；内容行左侧以 14px 字号显示值，右侧用 11px 置信度小标签搭配 12px 细线 Gauge（仪表盘）图标。图标沿用标签文字颜色，不独立加重；悬停可查看 Confidence 数值说明。
- 嵌套字段使用紧凑的父级／字段标题，表格值补充业务行号，区分 City、Line1 等同名字段，不额外增加标题行。
- 字段与数组单元格的正文值统一使用参考截图正常正文的 `#1E3A2A` 深色，不随低／正常／未知置信度、表格类型、阈值或高亮开关变色；该正文颜色不表示已达高置信度。保留 14px／600 字重和原换行布局。
- 仅 Confidence 标签的分数、Gauge、文字及底色继续表达原有状态：低置信度红／粉色、正常字段绿、正常单元格蓝、未知灰；不修改真实分数、阈值分类或 N/A。该调整不影响 Fields 低置信度提示、源区语义填充或段落 Content 样式。
- 数值使用 `0–1` 表达，例如 `0.64`、`0.95`；不可用时明确标记，不伪造 `0.00`。
- 常规置信度显示两位小数；若四舍五入会与真实阈值分类矛盾，则按需增加精度，极近的边界值保留真实数值。列表、Flyover、详情和辅助说明使用同一规则，不改变原始值或阈值判定。
- 大值允许换行，内容区最高 112px，超出后内部滚动；不截断原始值。保持边界约束和键盘等价信息，支持 Esc 关闭。

## 8. Fields 表格、搜索与排序

### 8.1 布局方案

- 默认两列：Field / Value。
- 对比方案三列：Field / Value / Confidence。
- 对象分组通过展开箭头、字重与轻量分隔区分，不与普通标量混淆。
- 数组在 Fields 内呈现内嵌表格，低置信度仅强调对应单元格的值。
- 根级、嵌套及可投影数组统一只在 Value 列显示 `N items`，展开／折叠均移除名称旁自动生成的 `[数量]`。不按 LineItems 等业务名做特例、不改实际名称；原始元素数、业务行号、完整数组摘要入口、F2、搜索和来源定位保持原样。
- 内嵌表格横向滚动时固定行号，原始行与单元格结构不改变。
- 横向滚动限定在内嵌表格的容器中；表格辅助说明也定位在该容器内，不泄漏到整个结果区形成第二条横向滚动条。
- 值操作入口使用固定的小型保留区域，悬停只显示入口，不改变值的可用宽度或导致文本重新省略。
- 折叠对象按原有子值顺序、以空格连接实际已返回值（如 `610 USD`），不按 AmountDue 等业务名做特例；嵌套对象可汇总其真实值，嵌套数组保留实际 `N items`，不把未返回子值当作真实内容。空对象、空字符串、`0`、`false`、`null` 与无返回分别表达，展开后恢复完整子结构。
- 普通长值和折叠摘要按实际 Value 列宽单行省略，不固定截取 N 个字符、不改变原值、不撑高行、不占用 Confidence 或定位按钮区域。折叠摘要使用正常 12.5px 值字体，实际长文本仍保留在 DOM／辅助说明中；不因悬停而改变宽度。
- `0`、`false`、空字符串、`null` 与未返回必须区分。
- 数量统计以全部叶字段为口径，包括未返回字段与数组单元格，另行说明返回值／缺失数量；筛选时显示“命中数／全部字段数”，低置信度按钮显示实际低置信度数量。

### 8.2 完整值、复制与键盘查阅

- 悬停或聚焦时显示统一的值操作菜单入口，普通字段与 Fields 内嵌数组共用；也可用 Shift + F10 打开菜单。完整值详情在右侧显示，不扩大左侧 Flyover，也不因为打开详情而跳页。
- 已打开的详情默认跟随新的显式单字段选择，复制操作同步使用新值；选择分组时关闭旧的单值详情。不提供隐式固定旧值的行为。
- 双列模式及无来源字段也可查看完整值、已有置信度、阈值比较状态；不能依赖左侧来源区域才能获得这些信息。
- 点击折叠摘要复用现有完整值面板并聚焦内容，字段上的 F2 也可查看；不自动展开、改变选择、重定位 Source 或新增大弹窗，关闭后回到同一字段焦点。数组折叠时同样可从实际数量摘要查看完整原值。
- 复制完整原值，不复制折叠摘要或 CSS 省略号；普通叶值保留原有显示／复制格式，对象与数组沿用完整原值 JSON。真正的空字符串复制为空内容，`0`、`false`、`null` 保持各自含义；未返回值不提供复制。
- 复制成功有明确反馈；剪贴板不可用或权限被拒绝时保留完整值，显示错误及手动复制提示，不误报成功。
- 复制反馈同时校验最新请求和当前字段／详情上下文，旧的成功或失败不能覆盖新的错误／成功提示，也不能重新打开旧详情；过期失败保留诊断日志，不占用当前字段反馈。
- 复制请求与上下文重置共用反馈版本：显式选择、清除选择、切换文档、切换／关闭详情都会使先前待完成的反馈失效。即使清除前后字段与详情 ID 均为空，或者切走后又返回同一文档，也不能接受旧回调。
- 结果区使用单个主字段焦点入口，上下键移动焦点、Enter 选择定位、F2 打开完整值详情；移动焦点本身不触发跨页跳转。
- UI-55 移除字段导航工具区的“查看当前选中值”信息按钮及专用单值判断，不再按无选择／单值／整组状态显示或禁用该入口。匹配计数和上一／下一字段保留；字段主入口／数组单元格上的 F2、值操作菜单、折叠摘要及完整值复制能力不变。详情仍可跟随后续显式来源选择，但不能重新抢走左侧焦点。
- 值操作菜单使用 240px 名义宽度及定位／详情／复制图标；文档菜单使用 224px 名义宽度。页码按钮为 30px，Flyover 默认间距及显式定位留白共用 12px 规则，避免页底卡片被裁切。
- 原有拖拽手柄的 Alt + Up／Down 排序保留；值详情可用 Esc 关闭并回到对应字段。
- 文档菜单和值操作菜单内部使用方向键、Home／End 移动；Tab／Shift+Tab 关闭菜单并继续从触发位置正常导航，Esc 关闭并返回触发按钮。焦点因其他操作离开菜单时，菜单也应关闭，不强行拉回焦点。
- 字段与浮层通过可访问说明表达置信度及其状态，不只依赖颜色。

### 8.3 搜索的原型约定

- 搜索图标和输入区作为一个整体，默认使用 1 CSS px 浅灰色圆角边框，悬停时略微加深；鼠标或键盘聚焦时只显示一层贴合原边界、向内绘制的 2 CSS px 蓝色焦点线，不叠加内部输入框轮廓或带间隔的外圈。状态切换不改变控件尺寸，其他控件的键盘焦点提示保持不变。
- 不区分大小写地匹配字段名、字段路径及显示值。
- 保留命中字段的父级路径，并自动展开匹配路径。
- 名称、路径或摘要命中对象／数组父级时，展示该父级的后代值；同时启用低置信度筛选时，仍按每个后代自身置信度过滤。
- 摘要匹配以真实内容为准：数组 `3 items` 与对象真实摘要（如 `610 USD`）可命中后代，普通对象不因虚构的 `N properties` 产生结果；沿用父级命中后展示后代、按各叶自身分数过滤的规则。表格限定范围内，祖先摘要及摘要搜索不能夹带范围外子值；显式完整值详情／复制仍使用原对象。
- 字段列表、数组行、导航顺序和命中数量共用一组匹配叶字段；例如搜索 `3 items` 应展示完整 LineItems 内容并统计其 24 个单元格，而不是显示分组却报告零结果。
- 数组保留命中行及原列结构，不因为搜索把单元格拆成错误的业务行。
- 搜索或低置信度筛选期间禁用拖拽，避免隐藏字段使落点含义不清；界面解释原因。
- 没有结果时明确显示空状态，可清除条件。

### 8.4 顺序与持久化

- 字段名左侧悬停／聚焦出现拖拽手柄。
- 同一父级内可排序，分组及其后代整体移动；拒绝跨父级放置。
- 不重排 LineItems 等数组业务行或其单元格，不改写原始 JSON。
- 提供键盘等价操作和可恢复默认顺序的入口。
- 同字段结构在当前浏览器重新打开后保留顺序；不同结构隔离，不能互相覆盖。
- 原型使用带格式标识与版本的 localStorage。损坏、不兼容或写入失败时明确提示；不得显示“已保存”或静默覆盖损坏数据。
- 新增字段在未指定顺序时按原始相对顺序追加；失效路径不导致字段消失。

## 9. 后续 React 组件能力要求

React 已实现下述可选顺序配置，仍保留原有两个必需输入；发布状态及嵌入示例见 [README](../../README.md#embedding)：

- 宿主可以直接配置初始字段顺序，而不必模拟拖拽。
- 支持接收用户排序变化，允许宿主管理持久化。
- 字段身份基于稳定路径，不依赖显示名称、数组序号变化或当前屏幕索引。
- 受控 `fieldOrder` 优先；否则同结构的合法浏览器偏好优先于 `defaultFieldOrder`，再回退到输入顺序。受控变更由 `onFieldOrderChange` 通知宿主，不另存一份竞争的浏览器顺序。
- 配置顺序不完整或 schema 更新时，仍显示未列出的真实字段，不修改输入数据。已实现的路径、优先级及受控规则见[开发计划](../dev-plan.md#ui-redesign-react-migration)。


默认访问地址为 `http://127.0.0.1:5188/`。使用 `--port 0` 可由系统分配空闲端口，启动输出显示实际地址。
