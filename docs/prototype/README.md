### 当前可操作范围

- **PDF / Receipt PNG**：加载对应真实源文件和原始 JSON；文件选择留在演示宿主。
- 字段悬停预览、点击固定；无定位字段仍可读，不补造区域。
- 上一页/下一页/跳页，缩放、适应页面/宽度、90° 旋转和平移；图片不显示 PDF 页码输入。
- 原始嵌套字段、多内容项切换，以及明确区分的缺失、`0`、`false`、空字符串、`null`。
- 数组项使用一开始的 `Item 1` 等可读名称但保留稳定数字路径；折叠父级不丢失后代选择。
- 固定多区域字段后，可在原文下方使用 Previous/Next 访问全部真实来源区域；组字段没有自身来源时按稳定顺序使用全部带定位后代。
- 对象/数组默认折叠；右侧箭头展开/折叠，**Hide missing fields** 默认开启，可切换查看未返回字段。
- Markdown 支持标题、列表、代码、GFM 及真实 CU HTML 表格；脚本、iframe、事件属性、危险 URL 和远程图片不执行/不请求。
- JSON 显示调用方传入的原始 envelope/inner result，不显示内部标准化模型；根节点展开，嵌套对象/数组可折叠并支持键盘操作。
- 独立的源文件/结果错误状态；解析警告可展开查看，坏文件和坏 JSON 可分别恢复。
- 原生 JPEG/PNG/BMP 的内容识别与方向规范化；HEIF/HEIC 仅在配置了本地候选资源的开发服务器中可用，分发构建明确拒绝。

### Fields 截图对齐

2026-10-10 按用户补充的 Studio Fields 截图调整可运行原型：

- 根字段使用 **12 px** 彩色实心圆点；没有真实定位时使用蓝色空心圆点，不重复给嵌套字段画圆点。
- 页码徽标紧邻名称，徽标高度 **20 px**；展开箭头在右侧，保留 SVG 图标及键盘焦点框。
- 默认折叠的组行高 **56 px**，单行值的普通字段高 **80 px**，均不含外侧 1 px 分隔线；字体、间距、灰色分隔线与参考对齐。
- 隐藏开关为 **40 x 20 px**；置信度右对齐，Fields 与原文预览栏统一显示两位小数；`0` 显示 `0.00%`，缺失置信度留空，不补造百分比。
- **Hide missing fields** 只过滤未返回值的字段；`0`、`false`、`null` 和空字符串仍显示。重新隐藏已选缺失字段时清除其选择与高亮。
- 组字段优先使用自身定位；没有自身定位时使用第一个带真实定位的后代。父子共享根字段颜色，展开、折叠或过滤不会改变高亮颜色，也不会写回原始结果。
- 来源页必须实际存在于当前源文件中。不存在时禁用相应根字段/组页码徽标并提供原因，在结果警告中列出页码；选择或悬停仍可查看原值，原文区明确提示文件与结果可能失配，不跳页、不画虚构高亮。
- 按后续截图反馈移除额外的 **Clear** 按钮，悬停、选中和展开均不会显示它；保留切换输入/内容和过滤已选缺失字段时的自动清理，不新增其他取消选择交互。
- Markdown 已启用；“…”是 JSON 入口并在选中后显示 JSON。Paragraphs、Tables、Code 仍禁用并提示未实现；不复制不可用的 token usage/pricing 功能。

[Fields 运行截图](interactive-fields.png)保留真实 `CountryRegion = USA` 与 `BillingAddress = 31.70%`，不替换为参考截图中的提取结果。本次更新可运行原型与运行截图；十份静态稿保留为 v2 评审依据，没有将静态控件当作已实现功能。

运行检查发现悬浮提示容易占据原文区域，现以**原文下方的小型预览栏**表达临时字段，避免遮挡文档。这是已记录的加固基线，不代表完整 UX/无障碍验收。HEIF/HEIC 现仅做本机集成验证；Markdown/JSON 已集成，但完整无障碍/触摸和其他专属结果标签仍未完成。

## 布局与职责

| 区域 | 原型设计 | 边界 |
| --- | --- | --- |
| 演示宿主 | 紧凑的源文件/保存结果选择与 PDF/PNG 样本入口。 | 负责文件交付、JSON 读取和重试；不上传、分析、认证或配置 Azure。 |
| 左侧源文件区 | 文档独立滚动/平移；底部上一页、下一页、跳页、缩放、适应及旋转。 | 核心仅渲染源文件和对应有效来源区域。 |
| 右侧 Fields | 真实层级、默认折叠/缺失过滤、只读值、可选置信度和来源页；固定行强调、独立滚动。 | 不要求调用方按分析器重写 JSON；不编辑服务结果。 |
| 其他结果视图 | Markdown 显示清洗后的原始内容；“…”入口显示原始 JSON 树；Paragraphs/Tables/Code 保留截图外观。 | Markdown/JSON 已真实交付并有大小限制；其余标签仍为禁用占位，不据外观宣称已交付。 |

核心仍接收 `source` 和原始 `result`。Studio 的 Run analysis、自动运行、资源选择、分析器编辑不进入可复用组件。

## 交互契约提案

以下规则已作为 v2 原型方向批准并实现基础行为，仍待用户在可运行页面中复核，不当作精确复现 Studio 的实测结论。

| 状态 / 操作 | 字段区 | 源文件区 |
| --- | --- | --- |
| 默认浏览 | 没有固定选择；对象/数组折叠，隐藏未返回字段。 | 不显示活动高亮，保留文档。 |
| 悬停可定位字段 | 临时行背景；不替换固定选择记录。 | 显示主要区域与临时提示卡，必要时导航到来源页。 |
| 移开悬停，没有固定选择 | 清除临时状态。 | 清除高亮和提示卡，保留当前页，不跳回悬停前的页面。 |
| 移开悬停，已有固定选择 | 恢复固定字段的强调。 | 恢复固定区域；必要时返回该字段的来源页，除非用户已手动翻页。 |
| 点击可定位字段 | 固定选择；选择其他字段替换固定项，不显示额外 Clear 按钮。 | 必要时导航并保留高亮；鼠标移开后提示卡消失，高亮不消失。 |
| 选择无定位字段 | 仍固定并显示值；空心圆点、无页码徽标，名称提示 No source region。 | 保留当前页，清除旧高亮，预览栏说明无定位；不补造位置或误关联旧区域。 |
| 手动翻页 | 保留固定字段，结束临时预览。 | 手动导航优先，不自动跳回；只有该页有对应区域才画高亮。 |
| 点击有效来源页徽标 | 重新定位已选字段。 | 导航到真实来源页；源文件未就绪时此入口不可用。 |
| 结果引用不存在的源页 | 禁用来源徽标并说明原因；保留字段值和结果警告。 | 选择/悬停时显示来源页不可用的明确提示，保留当前页，不画高亮；换成匹配结果后恢复。 |
| 展开/折叠组 | 切换真实后代，折叠时保留已选后代的组行强调。 | 保留固定区域与根字段颜色，不因折叠变色。 |
| 隐藏未返回字段 | 不修改结果；已选缺失字段被过滤时清除选择。 | 清除被过滤项的高亮，不改页码或缩放。 |
| 更换输入 | 取消过期任务、清除不再有效的选择。 | 不继续显示旧文档或旧区域。 |

悬停跳页只在进入一个可定位字段时触发，不因列表重绘连续触发。**手动翻页优先于预览恢复**已通过状态测试和真实 PDF 浏览器场景；后续仍需在更复杂的结果中继续检查，不能据此宣称所有跨页组合都已覆盖。

字段颜色只用于区域匹配，不表示正确性或置信度等级。P0 使用主要区域并保留其他区域数据，精细多区域、数组/表格与移动/触摸交互仍属于后续范围。

## 值与异常状态

| 输入情况 | 当前可运行原型呈现 |
| --- | --- |
| 没有返回字段值 | `Not returned`；不将其当成 0 或空字符串。 |
| 合成边界输入的 `0` / `false` / `null` | 分别显示 `0`、`false`、`null`，不被缺失过滤隐藏；已在明确标注的合成浏览器场景验证，不视为服务输出。 |
| 空字符串 | 明确显示空字符串状态，与未返回值区分。 |
| 置信度为 0 | `0.00%`；不当成缺失。 |
| 缺失置信度 | 不显示百分比或占位符；不补造 0，不设未经批准的阈值。 |
| 缺失/无效来源定位 | 保留值与可用置信度；空心圆点、无徽标，名称/预览提示无定位；无效区域另有可见警告，不画虚构区域。 |
| 有定位但源文件没有该页 | 保留真实定位和提取值；徽标禁用，显示 `unavailable-source-page` 警告，活动字段另有明确原文区错误提示。 |
| 源文件加载/失败 | 左侧独立状态，真实字段仍可查看；定位与源文件控件暂不可用。 |
| 空结果 | 右侧空状态，有效文档与控件可用。 |
| JSON 无法读取 | 右侧明确诊断，不能假定其 API 版本；有效源文件仍可用。 |
| 结构/版本错误或部分无效区域 | 显示带路径的错误/警告，保留其他有效输入；不静默忽略问题。 |
